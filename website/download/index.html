TRANSPARENCY

How every release is published

Every download is accompanied by verifiable integrity data so you can confirm exactly what you installed.

01

Signed APK

A single universal installer (ARM64, ARMv7, x86, x86_64) produced through a reproducible, auditable build — never an unsigned debug build.

02

SHA-256 checksum

A checksum file published alongside the installer so you can verify the binary matches the official build byte-for-byte.

03

Release notes

A complete changelog for every version — what was added, improved, fixed, and changed — kept in sync with the repository history.

GUIDE

How to install

  1. 1
    Get the installer

    Download the signed APK from the official GitHub release alongside the checksum file.

  2. 2
    Verify

    Compare the SHA-256 checksum of the downloaded file against the published checksums to confirm integrity.

  3. 3
    Install

    Enable installation from unknown sources if prompted, then open the installer and follow the on-screen steps.

FAQ

Frequently asked questions

When will SONARA be released?

SONARA 1.3.1 is available now. Grab the APK above — new versions are tagged on GitHub as they ship.

Will it cost money?

No. SONARA is free, open source software under GPL-3.0, with no ads, no paywalls, and no paid tiers.

Can I contribute?

Yes. The source is public and welcomes contributions of every kind. See the repository for details.

Is my data sent anywhere?

You can use SONARA without logging in. See the Privacy page for a full breakdown of permissions and third-party integrations.
