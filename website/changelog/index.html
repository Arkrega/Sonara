RELEASE HISTORY

Changelog

Every release is documented here: what was added, improved, fixed, and changed. New entries are published with each tagged release.

Version 1.3.3

18 November 2026

The player's home on the web now lives at sonara.my.id.

Highlights

  • About opens the official site at sonara.my.id
  • The site is now available in Indonesian and English
  • Version bump only; no playback or library changes

Version 1.3.2

18 November 2026

The website moved, so the in-app links follow it.

Highlights

  • About opens the new site on Vercel
  • Updates keep downloading and installing inside the app
  • Version bump only; no playback or library changes

Version 1.3.1

18 November 2026

Bahasa Indonesia, from the first launch screen to the update prompt.

Highlights

  • Full Indonesian translation: onboarding, Profile, Mood & genres, About and support, Reverb, playback speed, and the update flow
  • Pick it in Settings → Content → App language, or let the app follow an Indonesian system language
  • Version bump only; no playback, library, or layout changes

Version 1.3.0

18 November 2026

Updates now find you inside the app, once a day, and install without a detour.

Highlights

  • New New Update chip in the top right of Home as soon as a newer release exists
  • The update prompt shows at most once a day, so a dismissal holds until tomorrow
  • Updates download and install straight from the app — the APK is verified against its SHA-256 checksum before the installer opens
  • Tapping the update notification opens the same in-app sheet instead of a web link
  • Download problems are reported in-app instead of bouncing to a browser

Version 1.2.0

18 November 2026

Support the project straight from the app, with a simpler About page behind it.

Highlights

  • About offers Support the developer: a QRIS code you can scan with any bank or e-wallet app
  • About carries a single credit; the Discord server, Telegram channel and coffee link are gone
  • No playback or library changes in this release

Version 1.1.1

18 November 2026

Maintenance release that turns the Last.fm integration on.

Highlights

  • Last.fm scrobbling, now playing and love/unlove work out of the box
  • No UI or playback changes since 1.1.0

Version 1.1.0

17 November 2026

Polish release for the SONARA identity: a cleaner launch, a redesigned Mood & genres wall, and account actions moved into a dedicated Profile tab.

Highlights

  • Intro shortened from 5.5s to 3.2s with no Home flash before it starts
  • Mood & genres rebuilt as generated artwork cards instead of colour boxes
  • New Profile tab in the navigation dock; the Home top bar is just the wordmark
  • Opening Search no longer pops the keyboard up automatically
  • Simpler account sheet — Settings lives in Profile
  • Quieter first launch: no SQLite PRAGMA error in the logs on every cold start

Version 1.0.0

16 November 2026 · Initial stable release

Initial stable release of SONARA — an independently branded, high-performance Android music player.

Highlights

  • Independent application identity (com.arkrega.sonara)
  • Clean, stable YouTube Music playback engine powered by AndroidX Media3
  • Full synchronized lyrics support
  • Offline music caching and downloads
  • Equalizer and advanced audio processing
  • Dedicated update channel with SHA-256 integrity verification
  • Modern Material 3 user interface
